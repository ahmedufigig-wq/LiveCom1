# سوق اليمن الذكي 🇾🇪

واجهة أولية عربية متجاوبة لسوق إعلانات مبوبة في اليمن.

## الحالة الحالية
- صفحة رئيسية عربية متوافقة مع الهاتف.
- أقسام للمنتجات والخدمات.
- بحث وتصفية للإعلانات التجريبية.
- نموذج تجهيز إعلان وإرساله عبر WhatsApp إلى رقم المعلن.
- لا توجد قاعدة بيانات أو لوحة إدارة أو تحصيل أموال في هذه النسخة.
- لا يتم نشر الإعلانات تلقائياً؛ يلزم ربط خدمة خلفية وقاعدة بيانات قبل الإطلاق التجاري.

## النشر
يمكن نشر ملفات HTML الثابتة عبر GitHub Pages بعد تفعيل Pages من إعدادات المستودع (Settings → Pages → Deploy from a branch → main → /(root)).
الرابط المتوقع بعد التفعيل: https://ahmedufigig-wq.github.io/LiveCom1/

## الخطوات التالية قبل استقبال العملاء
1. إضافة قاعدة بيانات ومراجعة الإعلانات.
2. إضافة لوحة إدارة آمنة وتسجيل دخول.
3. وضع سياسة خصوصية وشروط استخدام وآلية بلاغات.
4. التحقق من وسيلة دفع متاحة في اليمن وربطها باسم المالك فقط.
5. اختبار الموقع على الهاتف.
